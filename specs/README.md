# Especificaciones

Lo que el equipo tiene que construir o resolver, escrito a partir del pedido y de la fuente (Notion, un documento…).
Una carpeta por área (`specs/<área>/<nombre>.md`). Los agentes las escriben y leen con las herramientas
`spec_write`, `spec_list` y `spec_read` del MCP de opensoma; el formato del contenido lo define el pack del equipo.
